# Simple Interest Calculator

A simple Bash script to calculate simple interest.

## Description

This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal: Initial amount of money
- Rate: Annual interest rate (percentage)
- Time: Period in years

## Usage

Run the script and enter the required values to calculate simple interest.
